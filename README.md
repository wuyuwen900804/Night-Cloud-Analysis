# Night-Cloud-Analysis
Clouds exert a major control on the atmospheric energy balance, yet the radiative effects of different cloud types under nighttime conditions remain poorly quantified due to limited observations and measurements. This study uses machine learning to investigate how nighttime cloud characteristics influence surface net longwave (NLW) radiation using data from a ground-based camera without near-infrared cut filter and longwave radiation. A data-driven framework is developed to extract and classify cloud features through dimensionality reduction, clustering, and a U-Net–based semantic segmentation to enable large-scale, automated analysis of nighttime cloud patterns. The results reveal that nimbus, stratocumulus, and stratus clouds exert the strongest positive influence on NLW radiation. The coefficients, representing the impact on NLW radiation (in W/m²) assuming 100% cloud cover at maximum brightness, are 27.53, 24.50, and 21.54, respectively. In contrast, thinner or more fragmented cloud types such as cirrus and cirrostratus have weaker effects, with corresponding coefficients of 6.89 and 2.51. This approach demonstrates the feasibility of combining ground-based imagery and machine learning to estimate nighttime NLW radiation, provide new insights into how cloud morphology governs nocturnal radiative exchange, and quantify cloud types from continuous measurements.
